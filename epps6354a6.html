Assignment 6

  1. Website Analysis

    a) Using JSON

    Reddit: Reddit uses JSON to allow people to access posts, comments, upvotes, and various other information. It uses a nested JSON structure which makes it easy to look at. The technologies that Reddit uses for creating their database is PostgreSQL to store user data and posts. They use Apache Cassandra for large-scale data. It uses Python for fetching JSON responses.

    b) Using XML

    OpenHistoricalMap: OpenHistoricalMap is a website that uses XML for data representation. It uses XML to store geospatial data which is structured using XML schemas. This data can be queried using technology like XQuery and xslt. The technology used would be XQuery, XSLT, and XML schemas.

  2. SQL Exercise:

    i)

    select student.ID

    from student S

    left outer join advisor A on student.ID = A.s_ID

    where A.s_id is NULL

    ii)

    select I.ID, I.name

    from instructor I

    where not exists (

      select C.course_id

  from course C

  where C.dept_name = I.dept_name

  and not exists (

        select T.course_id

        from teaches T

        where T.ID = I.ID and T.course_id = C.course_id

  )

    )

    order by I.name
